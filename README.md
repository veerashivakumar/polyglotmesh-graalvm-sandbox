# PolyglotMesh
## GraalVM Multi-Language Runtime Sandbox

PolyglotMesh is a developer-focused multi-language execution
environment built using Java, GraalVM, Spring Boot, React
and Monaco Editor.

### Project Objective
Execute Python, JavaScript and other supported languages
inside a controlled GraalVM Polyglot runtime.

### Technology Stack
- Java 21
- GraalVM
- Spring Boot 3
- Spring WebFlux
- React
- TypeScript
- Monaco Editor
- Docker

### Project Structure
- backend/ - Java and Spring Boot application
- frontend/ - React developer dashboard
- docs/ - Technical documentation
- assets/ - Project images and design assets
